# X Practice Copilot｜隐私与数据边界

## 本地保存

- 帖子上下文、灵感、实践、证据说明和草稿保存在浏览器 `chrome.storage.local`。
- 用户选择的截图只保留在当前 Side Panel 会话内；刷新或关闭后不会持久化。
- 扩展不自动发布、点赞、回复或关注。

## 本机 bridge

- 扩展只访问 `http://127.0.0.1:4317`，不读取模型密钥。
- `OPENAI_API_KEY` 与 `OPENAI_BASE_URL` 只由本机 bridge 进程读取。
- bridge 只绑定回环地址，锁定文字模型和接口，并限制来源与请求大小。
- 只有用户主动点击生成时，当前帖子上下文才会交给文字模型。
