# X Practice Copilot｜隐私与数据边界

## 本地保存

- 帖子上下文、灵感、实践、证据说明和草稿保存在浏览器 `chrome.storage.local`。
- 当前公开 X 视频只下载到本机临时目录，截帧完成或失败后立即删除；不会把原视频上传给模型。
- 原视频和单张代表帧只存在于本机临时目录；每个场景的早、中、晚 3 帧会被合成为九宫格，用户确认前不会交给视觉模型。
- 扩展不自动发布、点赞、回复或关注。

## 本机 bridge

- 扩展只访问 `http://127.0.0.1:4317`，不读取模型密钥。
- `OPENAI_API_KEY` 与 `OPENAI_BASE_URL` 只由本机 bridge 进程读取。
- bridge 只绑定回环地址，锁定文字模型和接口，并限制来源与请求大小。
- 只有用户主动点击生成时，当前帖子上下文才会交给文字模型。

## 尚未启用

- 个人飞书身份与 Base 尚未核验，远程 repository 当前拒绝读写。
- 只有用户勾选并主动提交的九宫格会经 Merouter 发送给 `gemini-3.7-flash`；原视频、音频和单张代表帧不会上传。
- 视频下载默认不读取 X 登录 Cookie；不处理私密、删除、区域受限或需要绕过权限的内容。
- Medeo 尚未接入，扩展只生成可复制的 prompt 框架。
- 公司租户禁止接入。
