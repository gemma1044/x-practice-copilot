# Chrome / Edge 人工回归清单

发布候选前，在 Chrome 与 Edge 各执行一次并记录浏览器版本、日期和结果。

## 安装与权限

- [ ] 以“加载已解压的扩展程序”加载项目根目录。
- [ ] 权限只有 Storage、Side Panel、X/Twitter 页面和本机 `127.0.0.1:4317`。
- [ ] 扩展包、页面源码和浏览器存储中没有模型密钥。

## X 页面

- [ ] 连续检查 10 条帖子，每条只出现一组、共三个 Copilot 入口。
- [ ] 三个入口分别打开评论、灵感、视频模式，并绑定正确帖子。
- [ ] 刷新与站内跳转后仍能注入，DOM 重绘不重复注入。
- [ ] 点击入口不会触发回复、点赞、转发或发帖。

## 恢复与升级

- [ ] bridge 未启动、未配置、超时和断网时保留当前帖子上下文。
- [ ] 旧 `xpc_inspirations` 数据升级到 `xpc_practice_state` 后仍可回读。
- [ ] 当前公开视频可经本机 bridge 下载、识别场景，并为每个场景截取早、中、晚 3 帧；原视频和单帧随后被清理。
- [ ] 每 3 个连续场景合成一张九宫格；取消部分九宫格后，只把仍选中的九宫格发送给 `gemini-3.7-flash`。
- [ ] 429、403、超时、超过 5 分钟或 250 MB 时停止，并保留当前帖子供稍后重试。
- [ ] 三条主流程各完成一次端到端验收，并记录已知限制。
