00 / Executive Summary

一句话结论

首版应做成一个“证据优先的 X 创作侧栏”：用户从当前帖子触发评论、收灵感或拆视频；AI 可以帮用户提炼、规划和表达，但涉及个人经历与数据时，必须先经过真实实践和证据回填。

关键产品判断“灵感收藏”不能只是另一个书签夹。它的终态应是：这条创意已经被拆成可执行的小实践，用户做过、留下证据，并能生成一条诚实且有独特信息量的公开表达。

02 / Why Now

背景、痛点与目标

PAIN 01

评论缺上下文

复制帖子去另一个 AI，再来回补作者、引用帖和自己的语气，慢且容易生成空话。

PAIN 02

灵感停在收藏

看见 GPT-6 等热点创意时想复刻，但没有把“为什么有效”变成当下可执行的验证。

PAIN 03

速度诱发失真

AI 最容易替用户补出并未发生的体验和数字，短期像高效，长期损害可信度。

成功长什么样

  • 从选中帖子到得到可用评论草稿，不需要离开 X 页面。
  • 保存灵感后，至少能得到一个 5–30 分钟可执行的最小实践。
  • 任何第一人称实践与结果数字，都能点回对应证据。
  • 视频不依赖“抓原始下载地址”也能完成结构拆解和 Medeo 复刻。
受众定位内部工具 / 自用。首要服务单个创作者的工作流，不为团队审批、多租户权限或商业化后台增加复杂度。
03 / Scope

MVP 不是少做一步，而是先闭合一条真实链路

能力MVP 处理理由
基于当前帖子生成评论✅ 保留：3 个角度、可改写、可复制最高频入口，验证扩展价值。
灵感卡 + 最小实践✅ 保留：来源、机制、假设、步骤、证据构成“不造假”的核心闭环。
证据约束写作✅ 保留：事实检测、证据映射、无证据降级是产品差异，而非附加安全提示。
视频分析⬇️ 降级：手动上传 3–8 张关键截图 → 视觉拆解先验证拆解与提示词价值，不承担视频处理。
Medeo 集成⬇️ 降级：先生成完整 prompt，一键复制；本地桥接可选先验证提示词质量，再承担任务管理。
自动下载 X 原视频❌ 后置：只做 best-effort受登录态、签名 URL、页面变更和平台规则影响。
自动发布 / 批量互动❌ 不做高风险、容易误发，也偏离“用户确认”。

05 / Feature Spec

三组核心功能

5.1 AI 评论助手

触发：帖子操作区扩展按钮、选中文本后的悬浮动作、侧栏粘贴链接。

行为：采集当前帖子和可见引用/线程 → 识别语言、论点和回复机会 → 扫描是否需要个人经验或数字 → 输出“观点补充 / 提问 / 实践型”三条草稿 → 用户选择语气、编辑和复制。

有证据

允许写“我刚跑了 3 次”，并把“3 次”关联到实验记录。

无证据

自动改为“我会想先跑 3 次看看”，或建议先创建最小实践。

验收：当前帖能生成 3 个不重复角度；默认不自动填入 X 回复框；无法读取上下文时明确提示输入范围。

5.2 灵感与真实实践

触发：“收为灵感”。

行为：保存快照 → 提炼吸引力机制、可迁移元素和用户可拥有的角度 → 生成最小实践（目标、步骤、预计时间、需采集证据）→ 用户执行并回填 → AI 生成基于事实的故事或评论。

约束：用户可直接写观察或猜测，但只有证据包满足最低要求后，状态才能进入“有证据”。AI 不把模型推断当用户事实。

5.3 证据优先写作

机制：先抽取草稿中的事实主张，再分别标记为“来源帖子事实 / 用户实践事实 / 推断 / 观点”。用户实践事实必须有证据引用，否则系统给出三种处理：补证据、改成计划式措辞、删除。

不可绕过的红线“帮我编一组合理数据”不能被当作普通风格需求执行；系统应转为生成实验方法、数据表模板和待填空草稿。

09 / Engineering Appendix

实现建议（研发可读，其他人可跳过）

浏览器扩展结构

Manifest V3。Content Script 负责识别当前帖子和用户选区；Side Panel 承载主要工作流；Service Worker 管理任务与权限；Offscreen Document 可用于标签页媒体处理。对 X DOM 使用集中适配层，避免选择器散落。

模型与密钥边界

扩展不持有模型密钥。它通过本机回环地址安全桥接访问 Merouter 的 OpenAI-compatible 接口，固定 OPENAI_BASE_URL=https://merouter.play.one2x.ai/v1，模型为 deepseek_v4_flash；真实 OPENAI_API_KEY 仅从本机环境读取。桥接校验扩展来源并限制模型、请求大小和能力。

飞书多维表格连接

同一本地桥接负责读写个人账号下的独立 Base，避免把飞书凭证放进扩展包。创建或写入前必须核验当前 user 身份属于个人账号；公司租户一律拒绝。按来源链接和关联灵感 upsert；Base 不可用时进入本地待同步队列。

视频 MVP

扩展只接收用户手动选择的 3–8 张 PNG、JPG 或 WEBP 截图，并按选择顺序交给独立视觉连接器。自动抽帧、视频解码、标签页录制、音频分析和精确时间码全部后置。

Medeo 连接

本机已存在 /Users/gemma/Projects/medeo-video-skill，支持上传 .jpg/.png/.webp/.mp4/.mov/.gif，以及把完整故事放入一次生成调用。MVP 先输出并复制完整 prompt；自动调用时通过本地桥接执行异步任务，展示结果而不暴露密钥。

平台与合规风险

X 页面结构、登录态与媒体 URL 会变化；扩展应限制到用户主动操作，不绕过访问控制，不批量抓取或自动发布。是否允许发布到 Chrome Web Store，以及目标浏览器是否只有 Chrome，需要在进入实现前确认。

10 / Acceptance

验收标准与成功指标

AC 01

评论可用

单条帖子在 10 秒内得到 3 条角度不同的可编辑草稿；无证据时不出现第一人称已实践断言。

AC 02

灵感闭环

一条帖子可创建灵感、最小实践、证据包，并据此生成带主张映射的评论。

AC 03

拆解可执行

上传 3–8 张截图后，产出按顺序组织的视觉结构与完整 Medeo prompt，不声称音频或时间码结论。

AC 04

权限可控

截图送视觉模型与 Medeo 生成都有明确的用户触发；密钥不进入扩展包。

建议观察指标

指标定义早期参考目标
评论采用率生成后被复制或填入回复框的会话比例≥ 35%
实践启动率灵感卡创建后 24h 内进入“实践中”的比例≥ 25%
证据完成率已启动实践中进入“有证据”的比例≥ 40%
失真拦截率被识别并改写/删除的无证据事实主张比例先做基线，不设越高越好
