# X Practice Copilot｜实现层（草案）

## 实施方案

**新增**：Manifest V3 扩展，含 X 内容脚本、侧栏、后台任务与本地桥接。评论与“收为灵感”共用 Merouter `deepseek_v4_flash` 文字连接器；灵感 AI 最多返回两题：机制候选与可直接执行的具体脚本 idea，界面只保留一个补充框。视频 MVP 只接收用户上传的 3–8 张关键截图，由独立视觉连接器分析，再生成可复制的 Medeo prompt。当前业务数据只写 Chrome Storage；个人飞书身份和 Base 核验通过后，才允许经同一个 `PracticeRepository` 接入远程存储，禁止使用公司租户。

**复用候选**：Merouter OpenAI-compatible 网关；待核验的个人 profile `personal-wuyue` 与 `Gemma X 灵感与实践` Base；Medeo 的文件上传、完整 prompt 单次生成与异步任务。候选配置不等于已连通，核验前均保持未配置状态。

## 兜底与边界

- 失败/超时：保留草稿与待同步队列，可重试；评论失败不阻塞灵感保存。
- 空态/脏数据：识别失败时框选文本或粘贴链接；上下文缺失时标明范围。
- 重复触发：按来源链接与关联灵感 upsert，不重复建记录。
- 回退：AI 输出均为草稿，可编辑、删除、撤销。
- 权限：仅在 X 激活；截图送视觉模型和 Medeo 生成前逐次提示；密钥只在本机桥接环境。
- 上游限制：截图少于 3 张时允许继续补充；格式不可读时只拒绝问题图片，不清空其他选择。
- 后置范围：视频解码、自动抽帧、场景检测、标签页录制、音频分析与精确时间码不进入 MVP。

## 基本数据 schema

| Base 表 | 粒度 | 关键字段 |
|---|---|---|
| X 灵感 | 一条来源灵感 | 链接、快照、机制、角度、状态 |
| X 实践记录 | 一次真实实践 | 假设、步骤、结果、证据、主张映射 |
| X 视频拆解 | 一次拆解任务 | 来源、关键截图顺序、视觉结构、Medeo prompt |

状态：`灵感 → 待验证 → 实践中 → 有证据 → 可发布`；无证据不得进入“有证据”。

## 验收要点

1. 单帖 10 秒内得到三条可编辑评论。
2. 无证据时不生成第一人称已实践事实。
3. Base 可回读灵感、实践、证据与评论来源映射。
4. 用户上传 3–8 张截图后，可得到按顺序组织的视觉结构与完整 Medeo prompt；界面不出现自动抽帧或录制承诺。
