# X Practice Copilot｜实现层（草案）

## 实施方案

**新增**：Manifest V3 扩展，含 X 内容脚本、侧栏、后台任务与本地桥接。评论与“收为灵感”共用 Merouter `deepseek_v4_flash`。视频把当前公开帖子 URL 交给同一个本机 bridge：`yt-dlp` 临时下载，FFmpeg 识别镜头切换，每场景在约 1/6、1/2、5/6 处截 3 帧，每 3 个场景按时间顺序合成一张九宫格；用户确认后由 Merouter `gemini-3.7-flash` 一次接收最多 5 张九宫格，生成结构化拆解和 Medeo prompt。当前业务数据只写 Chrome Storage；个人飞书核验后才允许经同一个 `PracticeRepository` 接入，禁止使用公司租户。

**复用候选**：Merouter OpenAI-compatible 网关；待核验的个人 profile `personal-wuyue` 与 `Gemma X 灵感与实践` Base；Medeo 的文件上传、完整 prompt 单次生成与异步任务。候选配置不等于已连通，核验前均保持未配置状态。

**挂载点**：继续复用视频 tab、`LoopbackMediaConnector`、`VisionAnalysisConnector` 与 `127.0.0.1:4317`。`src/bridge/media.js` 返回场景、三帧时间点和九宫格；`/v1/vision/analyze` 把原帖正文、场景映射和九宫格一并交给 Gemini，并由 bridge 用本机起止时间覆盖模型时间；侧栏展示来源模型判断和逐 clip 时间轴，不把 3N 张单帧逐张传给模型。

**开发更新**：`scripts/watch-extension.js` 监听既有 `src/` 与 `manifest.json`，变化后覆盖同步到原 `dist/x-practice-copilot-extension`。Chrome 仍由用户点击刷新加载，避免插件自行重载打断操作。

**本机配置入口**：项目根目录 `.env` 是唯一 Key 填写位置，已被 Git 忽略；`npm run bridge` 自动加载它。`.env.example` 只保存空 Key、固定 Merouter Base URL 和当前打包目录的扩展 ID，便于恢复配置结构。扩展前端仍不读取、保存或转发 Key。

## 兜底与边界

- 失败/超时：保留草稿与待同步队列，可重试；评论失败不阻塞灵感保存。
- 空态/脏数据：识别失败时框选文本或粘贴链接；上下文缺失时标明范围。
- 重复触发：按来源链接与关联灵感 upsert，不重复建记录。
- 回退：AI 输出均为草稿，可编辑、删除、撤销。
- 权限：仅处理用户当前打开并主动确认的公开 X 帖子；默认不读取 Cookie；帧送视觉模型和 Medeo 生成前逐次提示。
- 上游限制：单任务、串行、IPv4、请求间隔 1 秒；限制视频时长、文件大小与命令超时。429 后至少冷却 15 分钟，403 也立即停止；不自动密集重试、不切换代理规避。
- bridge 未启动/未配置：显示明确状态并保留当前帖子；上游超时或脏 JSON 转成可重试错误。
- Key 无效：Merouter 错误归一为可重试的上游错误，不把 Key 写入响应或日志；扩展 ID 不匹配时拒绝请求。
- 数据升级：旧 `xpc_inspirations` 在首次写入时迁移到版本化状态，成功后移除旧键。
- 部分成功：场景识别失败时降级为整段一个场景、截 3 帧；个别场景不足 3 帧时跳过，至少一张九宫格才可进入视觉分析。
- 回退：下载或抽帧失败时保留来源帖子，可稍后重试；不恢复旧的手动截图主路径。
- 模型失败：Gemini 超时、脏 JSON 或拒绝时保留九宫格，可单次手动重试；不改用文字模型假装识图。
- 模型归因：只有原帖正文、可见字幕或水印明确出现模型名时才填写；否则返回“未识别”，同时保留证据说明。
- 后置范围：登录 Cookie、批量抓取、逐帧动作识别、光流、标签页录制、音频分析和代理轮换不进入 MVP。

## 基本数据 schema

| Base 表 | 粒度 | 关键字段 |
|---|---|---|
| X 灵感 | 一条来源灵感 | 链接、快照、机制、角度、状态 |
| X 实践记录 | 一次真实实践 | 假设、步骤、结果、证据、主张映射 |
| X 视频拆解 | 一次拆解任务 | 来源摘要、明确提到的模型及证据、clip 起止时间、每段内容与叙事作用、九宫格顺序、Medeo prompt |

状态：`灵感 → 待验证 → 实践中 → 有证据 → 可发布`；无证据不得进入“有证据”。

## 验收要点

1. 单帖 10 秒内得到三条可编辑评论。
2. 无证据时不生成第一人称已实践事实。
3. Base 可回读灵感、实践、证据与评论来源映射。
4. 每个保留场景恰有早、中、晚 3 个时间点；每张九宫格最多承载 3 个连续场景，Gemini 只收到用户确认的九宫格。
5. `gemini-3.7-flash` 返回原帖语义、带证据的模型判断、逐 clip 内容与完整 Medeo prompt；clip 时间必须与本机场景边界一致，动态描述限定为“采样帧之间的变化”。
