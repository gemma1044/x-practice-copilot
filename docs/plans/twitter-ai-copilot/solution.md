# X Practice Copilot｜方案层（草案）

## 面向谁

内部工具 / 自用：给需要高频浏览 X、评论互动和复刻内容创意的个人创作者使用，把“看到内容”到“完成真实实践并形成可发布观点”的人肉链路缩短。

## 痛点

现在看到值得回应或复刻的帖子后，需要在多个工具间复制上下文、临时想评论、另建笔记、补做实验、截图拆视频。最危险的摩擦是：为了快速发言，AI 容易补出用户没有做过的实践或数据。成功不是多生成几段文案，而是让每个事实性表达都能追溯到真实证据。

## 主路径

1. 用户浏览或点选一条帖子；扩展识别正文、作者、链接及可见上下文。
2. 用户选择“写评论”“收灵感”或“拆视频”。
3. 写评论：系统先判断是否涉及个人经历/数据，再生成三种可编辑评论；无证据时只给观察、追问或实践建议，不虚构经历。
4. 收灵感：AI 只问两题——选择可复用机制，再选择一个包含对象、冲突和执行方式的具体脚本 idea；用户可补充一句，确认后系统再保存。
5. 用户执行实践，回填截图、链接、日志或结果数字；系统区分“计划、已执行、有证据”。
6. 系统只基于已记录证据生成可发布的评论或故事，并标出每个事实依据。
7. 拆视频：用户手动上传 3–8 张关键截图；系统按上传顺序分析开头钩子、版式、镜头变化与收束方式，产出复刻方案和 Medeo 提示词。
8. 用户确认后手动复制发布，或把完整提示词交给本地 Medeo Video Skill。

## 本期不做什么

- 不自动替用户发布评论或批量互动。
- 不自动宣称用户做过实验，也不生成无来源数字。
- 不把抓取 X 原始视频下载地址作为首版刚需。
- 视频 MVP 不上传视频、不自动抽帧、不录制标签页，也不承诺音频节奏与精确时间码分析。
- 不在扩展前端保存模型密钥。
- 不做团队协作、账号增长看板和跨平台内容管理。
