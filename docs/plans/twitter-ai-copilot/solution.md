# X Practice Copilot｜方案层（草案）

## 面向谁

内部工具 / 自用：给需要高频浏览 X、评论互动和复刻内容创意的个人创作者使用，把“看到内容”到“完成真实实践并形成可发布观点”的人肉链路缩短。

## 痛点

现在看到值得回应或复刻的帖子后，需要在多个工具间复制上下文、临时想评论、另建笔记、补做实验、截图拆视频。最危险的摩擦是：为了快速发言，AI 容易补出用户没有做过的实践或数据。成功不是多生成几段文案，而是让每个事实性表达都能追溯到真实证据。

## 主路径

1. 用户首次使用时，在本机 `.env` 只填写 Merouter Key，并运行 `npm run bridge`；Key 不进入扩展或 Git。
2. 用户浏览或点选一条帖子；扩展识别正文、作者、链接及可见上下文。
3. 用户选择“写评论”“收灵感”或“拆视频”。
4. 写评论：系统先判断是否涉及个人经历/数据，再生成三种可编辑评论；无证据时只给观察、追问或实践建议，不虚构经历。
5. 收灵感：AI 只问两题——选择可复用机制，再选择一个包含对象、冲突和执行方式的具体脚本 idea；用户可补充一句，确认后系统再保存。
6. 用户执行实践，回填截图、链接、日志或结果数字；系统区分“计划、已执行、有证据”。
7. 系统只基于已记录证据生成可发布的评论或故事，并标出每个事实依据。
8. 拆视频：用户确认处理当前公开帖子后，本机下载视频并识别镜头切换；每个场景截取早、中、晚 3 帧，每 3 个场景合成一张九宫格。用户确认九宫格后，由 Merouter `gemini-3.7-flash` 结合原帖正文判断内容主题与明确提到的生成模型，并按本机时间轴输出每个 clip 的起止时间、内容和叙事作用，最后产出 Medeo 提示词。
9. 用户确认后手动复制发布，或把完整提示词交给本地 Medeo Video Skill。

视频页保持单线任务结构：默认只显示当前可执行动作，说明折叠到对应位置的感叹号；完成视觉分析后才展开标注与 Medeo Prompt。

## 本期不做什么

- 不自动替用户发布评论或批量互动。
- 不自动宣称用户做过实验，也不生成无来源数字。
- 不把抓取 X 原始视频下载地址作为首版刚需。
- 视频 MVP 不接受批量抓取，不读取登录 Cookie，不处理私密、删除、区域受限或需绕过权限的视频；不录制标签页，也不承诺音频节奏分析。
- 原视频和单帧只进入本机临时目录，视觉模型只在用户确认后接收合成九宫格；任务结束或超时后清理临时文件。
- 本期不分析音频，不把三张采样帧之间的变化冒充连续动作事实；场景过多时最多保留覆盖全片的 15 个场景、5 张九宫格。
- 原帖和画面都没有明确模型证据时标注“未识别”，不根据风格猜模型；clip 台词只记录可见字幕，不推断音频。
- 不在扩展前端保存模型密钥。
- 不做团队协作、账号增长看板和跨平台内容管理。
